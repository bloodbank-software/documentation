The **Notification** module helps the team manage notification batches used for donor communication. It is connected to the donor messaging workflow, where selected donors are grouped and messages are sent as a batch. This module allows users to review notification batches, search for a specific batch, open batch details, and view the donor records included in each batch.

## Overview

The Notification module is used to track communication batches created for donor messages.

From this page, users can:

- view all notification batches in one place
- search for a batch quickly
- open a batch to view detailed information
- see the donors included in the batch
- understand how the notification batch is linked to donor messages

This module is important because it gives the team a clear view of message-based communication activity.

![Notification batch list](/screens/notification/Notifiaction_Batch_List.png)

## Purpose

The main purpose of this module is to organize donor message notifications into batches so that communication can be tracked and reviewed easily.

Instead of checking donor messages separately, users can open the notification module and see batch-level information and donor-level details in a structured way.

## Page Layout

The Notification page usually contains:

- a batch listing area
- a search option
- an action column for each batch
- a batch details view
- donor details inside the selected batch

The layout is designed so users can quickly move from the batch list to the batch details without losing context.

## Batch Listing

The batch listing shows all notification batches created in the system.

![Notification batch list](/screens/notification/Notifiaction_Batch_List.png)

### What This Screen Shows

- batch records in a table or list format
- batch identifiers or batch names
- batch-related summary information
- status or result information where available
- an action column for opening batch actions
- pagination and page size controls

### How to Use This Screen

1. Open the **Notification** module.
2. Review the available batches in the list.
3. Check the batch name or identifier.
4. Review the batch details shown in the row.
5. Use the action area to open the required batch.
6. Move to the next page if more records are available.

### Why This Screen Matters

This screen gives a quick view of all notification batches and helps the team identify the right batch before opening it.

## Search Batch

The search option helps users find a specific batch without scrolling through the full list.

![Notification batch search](/screens/notification/Notifiaction_Batch_Search.png)

### What This Screen Shows

- search field for batch lookup
- filtered results based on the entered text
- batch rows matching the search term
- list updates after search is applied

### How to Search a Batch

1. Open the **Notification** module.
2. Use the search field at the top.
3. Enter the batch name, batch id, or related keyword.
4. Wait for the results to update.
5. Review the filtered list.
6. Open the required batch from the results.

### Important Note

Use search when the batch list is long or when you already know part of the batch name or message reference.

## Batch Actions

![Notification batch actions](/screens/notification/Notifiaction_Batch_List_Action.png)

### What This Screen Shows

- action icons or menu options for each batch
- a way to open batch details

1. Find the required batch in the list.

### Why This Section Matters

## Batch Details

When a batch is opened, the system shows the batch details page.

![Notification batch details](/screens/notification/Notifiaction_Batch_Single_List_Details.png)

### What This Screen Shows

- selected batch information
- batch summary or header details

### How to Read This Screen

1. Open the batch from the listing page.
2. Review the batch header and summary details.

### Important Note

## Donor Details in a Batch

A notification batch may contain donor records that were included when the message was sent.

![Notification batch donor details](/screens/notification/Notifiaction_Batch_Single_List_Donor_Details.png)

### What This Screen Shows

- donor rows or donor cards inside the selected batch
- donor name or reference details
- contact or communication-related information where available
- recipient-level data linked to the notification batch
- donor-specific message tracking inside the batch

### How to Use This Screen

1. Open the required notification batch.
2. Review the donor details displayed in the batch.
3. Check which donors were part of the notification.
4. Use the donor information to verify message targeting.
5. Review the batch recipients when auditing communication history.

### Why This Screen Matters

This screen helps users confirm which donors were included in the message batch and whether the communication was sent to the correct audience.

## How This Module Connects to Donor Messages

The Notification module is connected to the donor messages workflow.

![Notification module usage with donor messages](/screens/notification/Notificaiton_module_UsageWithDonorModule_DonorMessages.png)

### What This Screen Shows

- donor selection or donor message workflow
- notification or messaging action from the donor module
- the point where selected donors are grouped into a batch
- the connection between donor messaging and notification records

### How the Flow Works

1. Open the donor-related workflow.
2. Select the required donor or donors.
3. Send the donor message.
4. The system creates or updates the related notification batch.
5. Open the Notification module to review the batch.
6. Check the donor details linked to that batch.

### Why This Connection Matters

This connection keeps donor communication organized and traceable. It allows the team to see which donors received messages and which notification batch was created for them.

## Important Notes

- Use the Notification module to review message batches, not to replace the donor message workflow.
- Search is the fastest way to find a batch when the list is large.
- Always verify the donor details inside a batch before using the record for follow-up.
- Use batch details to audit communication history when needed.
- The Notification module is mainly for tracking and reviewing donor message batches in a structured way.
