The **Screening & Testing** module is used for laboratory screening of quarantined blood units. It helps staff review pending units, search and filter records, open the testing form, update screening results, and upload the final test report when required.

## Overview

This page shows all blood units that need screening or testing review.

From this page, users can:

- view units that are pending or completed
- search by unit ID
- filter by blood group, source type, and status
- open the testing form for a selected unit
- update test results
- upload the test report
- track the progress of each unit through the screening workflow

![Screening and Testing overview](/screens/screning-testing/Screening_Testing_Listing_Overview.png)

## Purpose

The purpose of this module is to manage the screening process for blood units before they move to the next stage of the workflow.

It helps the team:

- identify which units still need testing
- record screening results in a structured way
- monitor testing status
- attach reports when testing is completed
- keep screening records organized and easy to review

## Page Layout

The Screening & Testing page is arranged into the following areas:

- page header with the module title and description
- pending count card on the top right
- search bar for unit ID
- filter controls for blood group, source type, and status
- results table showing all matching units
- action column for opening the testing form or upload action
- pagination at the bottom

### Fields and Columns

The table may include the following columns:

- **Unit ID** - unique blood unit number
- **Source Type** - source of the blood unit
- **Blood Group** - blood group of the unit
- **Component Type** - component type such as RBC, CRYO, or WB
- **Collection Date** - date the unit was collected
- **Location** - storage or quarantine location
- **Reason** - reason or screening note
- **Status** - current screening status
- **Action** - button used to open the testing or upload action

## Screening Status

The status column helps users understand the current stage of each unit.

Common status values shown on the page may include:

- **Pending**
- **Quarantined**
- **Stored**
- **Completed**
- **Tested**
- **Failed**

### What the Status Means

- **Pending** - the unit still needs screening attention
- **Quarantined** - the unit is waiting for screening results
- **Stored** - the unit is available in storage after completion
- **Completed** - the screening or related action is finished
- **Tested** - the screening result has been entered
- **Failed** - the unit did not pass screening

When a unit is completed, the row action may change to show upload-only actions instead of the full testing action.

![Completed status shows upload actions only](/screens/screning-testing/ScreeningTesting_CompletedStatusonlyshowupload_actions.png)

## Search and Filters

The top section of the page allows users to narrow down the results.

### Search

The search field is used to find a unit by its unit ID.

### Filters

Users can filter the list by:

- **Blood Group**
- **Source Type**
- **Status**

The **Clear** button resets the selected search and filter values.

![Search and filter controls](/screens/screning-testing/ScreeningTesting_Filters_and_Search.png)

### How to Use Search and Filters

1. Open the **Screening & Testing** page.
2. Type a unit ID in the search field.
3. Select one or more filter values if needed.
4. Review the updated list.
5. Use **Clear** to remove the current search and filter values.

## Testing Action

Each row in the table has an action button on the right side.

This button is used to open the testing form for the selected unit.

Depending on the status of the unit, the available action may change. For example:

- pending or quarantined units may show the testing action
- completed units may show upload-related actions
- the action reflects what the user can do next in the workflow

### How to Use the Action Button

1. Find the required blood unit in the list.
2. Check the current status of the unit.
3. Click the action icon in the **Action** column.
4. The testing form opens for that unit.
5. Review the unit information before entering test details.

## Update Testing

The update testing screen is used to enter or edit laboratory test results for a selected blood unit.

This form may include:

- unit information
- screening test fields
- tested date
- tested by
- remarks
- upload report option
- update button
- cancel button

![Testing update form](/screens/screning-testing/ScreeningTesting_testingUpdate_Form.png)

### How to Update Testing

1. Open the **Screening & Testing** list.
2. Click the testing action icon for the required unit.
3. Review the unit details shown at the top of the form.
4. Enter or update the screening results.
5. Select the testing date.
6. Choose the staff member who performed the test, if required.
7. Add remarks if needed.
8. Review all values before saving.
9. Click **Update** to save the testing details.

## Upload Report

Some completed or tested units allow report upload from the action column or from the testing screen.

This is useful when the laboratory report or supporting document needs to be attached to the record.

### What Users Should Do

1. Open the relevant blood unit record.
2. Use the upload-related action if it is available.
3. Select the report file.
4. Confirm that the correct document is attached.
5. Save the record.

## Important Notes

- Only users involved in screening and testing should update this module.
- Always verify the unit ID before saving any result.
- Make sure the status is correct before moving the unit forward in the workflow.
- Upload the report only when the final test document is ready.
- Use **Clear** if the current filters are hiding the record you need.
- The screening results should be entered carefully because they affect the next stage of the blood unit workflow.
