The **Donor Registration** module is the onboarding flow used by new donors to create their account and complete the required details before they can continue in the blood bank system.

This flow starts from the public entry point, verifies the donor's mobile number, collects personal and contact information, and ends with a successful submission confirmation.

## Overview

The Donor Registration module helps a new donor join the system in a guided step-by-step process.

The flow is designed to:

- collect donor details in a structured way
- verify the donor's mobile number
- capture location and identification details
- record consent and notification preferences
- complete registration with a final success confirmation

## Purpose

The purpose of this module is to make donor onboarding easy, secure, and consistent.

Instead of collecting details manually, the system guides the donor through each step and validates the information before submission.

This helps:

- reduce missing information
- verify the donor before registration
- keep donor records accurate
- provide a simple onboarding experience

## Entry Points

A donor or visitor can begin the registration flow from the public landing page.

The main entry point is the **Donate Now** button, which starts the donor registration process.

![Donate Now button](/screens/donor-registration/Blood_Bank_Donate_Button.png)

## Sign In and Password Recovery

If the user already has an account, they can use the sign in page to access the system.

The sign in screen also provides access to password recovery in case the user forgets their password.

![Sign in page](/screens/donor-registration/Blood_Bank_Signin.png)

### Sign In

The sign in page includes:

- email field
- password field
- human verification
- sign in button
- forgot password link

This screen is used for users who already have an account in the system.

### Password Recovery

If the user forgets the password, the reset password screen allows them to request a reset link.

![Reset password page](/screens/donor-registration/Blood_Bank_Register_Reset_Password.png)

The user needs to enter the registered email address and follow the reset link sent to the inbox.

## Start Donor Registration

When a new donor wants to join the system, the registration flow begins with mobile number verification.

The donor enters a mobile number and requests an OTP to continue.

![Mobile number entry](/screens/donor-registration/Blood_Bank_Register_With_Mobile_Number.png)

### What This Screen Shows

This screen usually includes:

- country code selector
- mobile number field
- send OTP button
- navigation to the next verification step

### How to Start Registration

1. Open the public blood bank page.
2. Click **Donate Now**.
3. Enter the mobile number.
4. Click **Send OTP**.
5. Wait for the verification code to arrive.

## Mobile Verification

The mobile verification step confirms that the donor owns the phone number entered during registration.

The donor must enter the OTP sent to the mobile number.

![OTP verification](/screens/donor-registration/Blood_Bank_Register_OTP.png)

### What This Screen Shows

This screen usually includes:

- OTP input field
- resend OTP option
- change mobile number option
- verify OTP button

### How to Verify the Mobile Number

1. Enter the OTP received on the mobile phone.
2. Review the number shown on the screen.
3. Use **Change mobile number** if the number is incorrect.
4. Click **Verify OTP** to continue.
5. Use **Resend OTP** if the code does not arrive.

## Personal Information

After mobile verification, the donor moves to the personal information section.

This step collects the basic details needed to create the donor profile.

![Personal information form](/screens/donor-registration/Blood_Bank_Register_Form1.png)

### What This Screen Shows

This screen may include:

- full name
- gender
- date of birth
- blood group
- mobile number
- email address

### How to Fill the Personal Information

1. Enter the donor's full name.
2. Select gender.
3. Enter the date of birth.
4. Select the blood group.
5. Confirm the mobile number.
6. Enter an email address if required.
7. Review the details carefully before moving to the next section.

## Donation History and Identification

This section collects background information that helps the blood bank understand the donor's previous donation history and identity proof.

![Donation history form](/screens/donor-registration/Blood_Bank_Register_Form_Continuation2.png)

### What This Screen Shows

This section may include:

- donation history questions
- ID proof type
- ID proof number

### How to Complete This Section

1. Answer whether the donor has donated blood before.
2. Select the appropriate ID proof type.
3. Enter the ID proof number.
4. Make sure the information matches the donor's official details.
5. Continue to the next section after reviewing the values.

### Why This Section Matters

These details help the blood bank verify the donor and keep records accurate for future reference.

## Location Details

The location section captures the donor's address and place information.

This information is used to store the donor's residence details and support contact or communication needs.

![Location details form](/screens/donor-registration/Blood_Bank_Register_Form_Continuation1.png)

### What This Screen Shows

This screen usually includes:

- use current location button
- search location field
- address field
- country
- state
- city
- pincode

### How to Fill the Location Details

1. Click **Use Current Location** if you want to auto-fill the address.
2. Or search for the location manually.
3. Enter the full address.
4. Select country.
5. Select state.
6. Select city.
7. Enter the pincode.
8. Check all values before saving.

## Consent and Preferences

This section records the donor's consent and communication preference.

The donor can choose how they want to receive notifications related to blood donation activities.

![Consent and preferences form](/screens/donor-registration/Blood_Bank_Register_Form_Continuation3.png)

### What This Screen Shows

This screen usually includes:

- consent checkbox
- notification preference selector
- email or SMS preference
- submit button

### How to Complete This Section

1. Read the consent message carefully.
2. Select the consent checkbox if you agree.
3. Choose the notification preference.
4. Confirm whether email or SMS is preferred.
5. Review the final details before submission.

## Submit Registration

Once all required details are completed, the donor can submit the registration form.

The submit action sends the information for final processing.

### How to Submit

1. Review every section one last time.
2. Make sure the mobile number, personal details, and address are correct.
3. Confirm the consent and preferences.
4. Click **Submit** to complete the registration.

## Registration Success

After successful submission, the system shows a confirmation page.

This page tells the donor that the registration process is complete and that a verification email has been sent if required.

![Registration success page](/screens/donor-registration/Blood_Bank_AfterRegistration_SucessPage.png)

### What This Screen Shows

The success screen usually includes:

- confirmation message
- email verification notice
- go to home button
- start over button

### What the Donor Should Do Next

1. Check the registered email inbox.
2. Follow the verification link if one is sent.
3. Return to the home page after completion.
4. Start over only if the donor wants to register again.

## Important Notes

- Mobile verification must be completed before the form can be submitted.
- Enter the mobile number correctly before requesting OTP.
- Review the personal, location, and identification details carefully before submitting.
- Consent and notification preferences should be selected as intended by the donor.
- The success page confirms that registration is complete, but any email verification steps should still be followed if shown.
