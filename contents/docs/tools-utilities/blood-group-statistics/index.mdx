The Blood Group Statistics page provides a quick summary of the current inventory status across all supported blood groups.

It helps users monitor stock availability, identify low-stock blood groups, and review overall inventory health from one screen.

<Note title="Read Only" type="note">
  This page is for viewing statistics only. It does not support add, edit, or delete actions.
</Note>

![Blood Group Statistics overview](/screens/tools-utilities/bloodgroup-statistics/BloodGroup_Statistics.png)

## Overview

The Blood Group Statistics page is used to review blood inventory health in a simple, read-only format.

Users can quickly see which blood groups are well stocked, which ones are low, and how many units are currently available or expired.

## Purpose

This page is used for inventory monitoring and decision-making.

It helps users understand:

- how many blood units are currently available
- how many units are expired
- which blood groups are running low
- which blood groups are healthy and sufficiently stocked

<Note title="Why this page matters" type="success">
  The data on this page helps staff plan collection, watch stock levels, and identify shortages early.
</Note>

The page is divided into three main areas:

- top summary cards that show overall inventory figures

## Low Stock Alert

When one or more blood groups fall below the desired threshold, the page shows a low-stock alert at the bottom.

<Note title="Low Stock Alert" type="warning">
  Use this warning to quickly identify blood groups that may need collection planning or replenishment.
</Note>
