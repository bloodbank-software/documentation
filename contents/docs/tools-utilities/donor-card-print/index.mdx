## Donor Card Printer

The Donor Card Printer is a utility page used to select donors and print donor cards in the required card format.

This tool helps staff quickly generate donor cards with the selected layout and identification details.

![Donor Card Printer overview](/screens/tools-utilities/donor-card-printer/DonorCardPrinter_Overview.png)

## Overview

The Donor Card Printer page allows users to search for donors, select one or more donors, choose a card format, and print the donor card.

This page is designed to make donor card printing simple, fast, and consistent.

## Purpose

The main purpose of this tool is to generate donor cards in a standardized format for daily operational use.

It is useful when staff need to print donor identity cards for:

- identification
- donor tracking
- verification
- card-based reference during operations

## Screen Layout

The page contains the following main parts:

- Card Format Selection
- Donor Search Box
- Donor Listing Table
- Selection Counter
- Print Card Button

The layout is designed so that the user can first choose the format, then select the required donors, and finally print the card.

![Donor Card Printer format selection](/screens/tools-utilities/donor-card-printer/DonorCardPrinter_FormatSelection.png)

## Card Format Selection

Before printing, the user must choose the card format.

Available formats may include:

- Compact Card
- Standard ID Card

Each format represents a different print size and card layout.

The selected format determines how the final donor card will appear after printing.

## Donor Search and Selection

The donor list can be filtered using the search box.

Users can:

- search for a donor by name or other available details
- select one donor
- select multiple donors at the same time

The table shows donor information such as:

- Name
- Mobile Number
- Age
- Gender
- Blood Group
- City

![Donor Card Printer search and selection](/screens/tools-utilities/donor-card-printer/DonorCardPrinter_SearchSelection.png)

## Print Action

Once the donor is selected, the **Print Card** button becomes active.

This ensures that the user cannot print until at least one donor is chosen.

The user can then click **Print Card** to generate the donor card output in the selected format.

![Donor Card Printer selected donors](/screens/tools-utilities/donor-card-printer/DonorCardPrinter_SelectedDonors.png)

## Printed Card Output

After printing, the donor card is displayed in the selected format.

The printed card contains the donor identification details in a clean and readable layout.

It usually includes:

- organization name
- donor name
- blood group
- DRN ID
- gender
- mobile number
- date of birth
- QR code

![Donor Card Printer output](/screens/tools-utilities/donor-card-printer/DonorCardPrinter_Output.png)

## Important Notes

- Choose the correct card format before printing.
- Select the required donor or donors carefully before printing.
- The Print Card button becomes available only after valid donor selection.
- The printed layout depends on the chosen format.
- Use this page only for donor card generation and printing.
