The Donation Reminder page helps staff find donors who are ready for a reminder, review their donation summary, and send notifications through the channels allowed by the organization.

![Donation Reminder overview](/screens/tools-utilities/donation-reminder/DonationReminder_Overview.png)

## Overview

The Donation Reminder module is used to identify eligible donors and send reminders in a simple, guided workflow.

Staff can use it to:

- filter donors based on blood group and last donation history
- review summary information before sending a reminder
- select one or more eligible donors
- send reminders through the configured communication channel

## Purpose

This page is used to support donor follow-up and reminder communication.

It helps staff:

- find donors who have crossed the required donation gap
- narrow the donor list using the available filters
- verify reminder details before sending
- send messages through WhatsApp, SMS, or Email depending on organization settings

## Send Reminders

After selecting the required donors, staff can send reminders through the chosen channel or channels.

![Send Reminders](/screens/tools-utilities/donation-reminder/DonationReminder_SendReminder.png)

### Reminder workflow

1. Apply the desired filters.
2. Review the eligible donor list.
3. Select one or more donors.
4. Choose the reminder channel or channels.
5. Click **Send Reminders**.

This sends the reminder to the selected donors using the configured communication method.

## Reminder Channel Configuration
