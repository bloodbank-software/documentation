## Getting Started

This section helps new users begin using the Blood Bank system in a simple and structured way. It explains the basic steps to access the application, understand the main screens, and start working with the core workflows.

### Before You Start

Before using the system, make sure you have the required access and basic information ready.

- Log in with your assigned username and password.
- Confirm that your account has the correct access for the tasks you need to perform.
- Keep donor details, collection information, and storage details ready if you are entering new blood units.

### First Login

When you open the Blood Bank application for the first time, you will be taken to the main dashboard after login.

- The dashboard gives a quick overview of the current system status.
- You can use the sidebar or menu to move between modules.
- Each module contains its own set of screens for managing related tasks.

### Understanding the Main Areas

The system is divided into modules so users can work in a clear and organized way.

- Dashboard provides a summary view of blood availability and operational counts.
- Donor module is used for donor registration, editing, and donor details.
- Inventory module is used for blood unit tracking, storage, and status handling.
- Lab Testing module is used for screening and test result updates.
- Settings and master data modules are used to manage supporting reference values.

### Typical Work Sequence

A typical Blood Bank workflow usually follows this order.

- Register or identify the donor or source.
- Add the blood unit into the system.
- Assign QR tracking if required.
- Complete screening or testing.
- Store the unit in the correct location.
- Handle reservation, issue, return, transfer, or discard when needed.

### How to Use the System Effectively

To work smoothly in the system, follow a few simple practices.

- Always verify the donor or source before creating a blood unit.
- Enter storage details correctly so the unit can be found later.
- Check the unit status before performing any action such as reserve, issue, or discard.
- Review the timeline or history when you need to understand what happened to a unit.

### Helpful Notes for New Users

A few screens may look similar, but they serve different operational purposes.

- Inventory is for active blood unit tracking.
- Lab Testing is for screening and result handling.
- Discarded or expired units are handled separately from active stock.
- QR-based lookup makes it easier to identify and manage a unit quickly.

### Next Steps

Once you are familiar with the basic navigation, you can move into the main modules and start using the system for daily operations.

- Learn how donor records are managed.
- Learn how blood units are added and tracked.
- Learn how screening, storage, and movement workflows work.
- Review the settings and master data used throughout the system.

This guide gives you the basic starting point. The next sections explain each module in more detail so you can use the system confidently in day-to-day blood bank operations.
