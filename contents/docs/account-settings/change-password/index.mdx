The **Change Password** section is used to update the user's login password securely.

## Overview

This page lets the signed-in user change their password whenever needed.

![Change Password](/screens/account/user-password/User_ChangePassoword.png)

## Purpose

The purpose of this page is to improve account security by allowing the user to create a new password without involving support.

## Page Layout

The page usually shows:

- password change area
- current password field
- new password field
- confirm password field
- update and cancel actions

![Change Password Form](/screens/account/user-password/User_ChangePassoword_Form.png)

## How to Change Password

1. Open **Change Password**.
2. Enter the current password.
3. Enter the new password.
4. Re-enter the new password in the confirmation field.
5. Make sure both new passwords match.
6. Click update to save the new password.

## Important Notes

- Use a strong password that is hard to guess.
- Do not share your password with anyone.
- Make sure the confirmation password matches before saving.
