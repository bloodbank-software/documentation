The **Account Settings** module is the place where users manage their own account-related information. It groups the main personal account functions in one place so they are easy to find and use.

## Overview

This module gives users a simple way to review and update their own account details.

From here, users can:

- view their profile information
- update profile and address details
- change their password
- review permission history
- review login history

![User Profile](/screens/account/user-profile/User_Settings.png)

## Purpose

The purpose of Account Settings is to let the user manage personal account information without needing help for every change.

It keeps account settings and account activity in one place.

## Module Structure

The Account Settings module contains four child pages:

- User Profile
- Change Password
- Permission History
- Login History

Each child page handles one account function, so the module stays simple and easy to navigate.

## What This Screen Shows

The overview screen shows:

- the current user profile summary
- an entry point to the account settings functions
- the main account sections listed in one place

Users can open any child page from this module when they want to edit profile details, change a password, or review history.

## Important Notes

- Use this module only for your own account settings.
- The detailed actions are available in the four child pages.
- This overview page is only for quick reference and navigation.
