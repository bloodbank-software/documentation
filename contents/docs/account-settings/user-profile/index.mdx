The **User Profile** section is used to view and update the user's personal details.

## Overview

This page shows the current profile information for the signed-in user.

Users can review their saved details and edit them when something changes.

![User Profile](/screens/account/user-profile/User_Settings.png)

## Purpose

The purpose of this page is to let the user keep their profile information current without needing help from support.

It helps the user update details such as name, contact information, and address information.

## Page Layout

The page usually shows:

- profile summary details
- an edit action
- saved personal information
- address-related information where applicable

## Edit Profile

![Edit User Profile](/screens/account/user-profile/User_Settings_Edit.png)

### What This Screen Shows

This screen shows the profile editing area where the user can start updating their details.

### How to Use This Screen

1. Open **User Profile**.
2. Click the edit option.
3. Review the current profile details.
4. Enter the corrected information.
5. Save the changes.

![Edit Profile Form](/screens/account/user-profile/User_Settings_Edit_Form.png)

### What This Form Shows

This form is used for editing user details such as personal information and contact details.

### How to Use This Form

1. Update the required fields.
2. Check the information carefully.
3. Click update or save when the details are correct.

![Edit Address Form](/screens/account/user-profile/User_Settings_Edit_Address_Form.png)

### Address Edit Form

Some profile updates also include address fields.

### How to Update Address Details

1. Enter the correct address information.
2. Review the location details.
3. Save the changes after confirming the values.

## Important Notes

- Update profile details carefully because they are part of the user's account record.
- Check address information before saving.
- Use this page only for the current user's profile.
