# Blood Request

The **Blood Request** module is used to manage patient blood requests from creation to final completion. It helps staff create new requests, review the request list, search and filter records, open request details, approve or reject requests, issue blood units, cancel issued allocations when needed, and track the status of each request.

This is one of the most important workflow modules in the system because it connects patient demand with blood inventory allocation and fulfillment.

## Overview

The Blood Request module helps the team manage incoming requests for blood and blood components.

From this module, users can:

- create a new blood request
- view all requests in a structured list
- search and filter requests
- review request details
- approve or reject requests
- issue blood units for approved requests
- cancel issued allocations when required
- track the request status from start to finish

## Purpose

The main purpose of the Blood Request module is to organize and track patient requests in a controlled workflow.

Instead of handling requests manually, the system stores each request with its required blood group, component type, priority, units, and approval status. This helps the team respond quickly and maintain a proper audit trail.

## Add Blood Request

Use the add form to create a new blood request.

![Add Blood Request form](/screens/blood-request/Blood_Request_Add_Form.png)

### What This Form Shows

This form includes:

- patient name
- contact number
- blood group
- component type
- units required
- required date and time
- priority
- reason
- add and cancel actions

### Field Guide

| Field | Description |
|---|---|
| **Patient Name** | The name of the person requesting blood. |
| **Contact Number** | Phone number used for communication. |
| **Blood Group** | The blood group required for the request. |
| **Component Type** | The blood component required, such as WB, RBC, FFP, or PLT. |
| **Units Required** | Number of units needed. |
| **Required Date & Time** | When the blood is needed. |
| **Priority** | Urgency of the request, such as Normal or High. |
| **Reason** | Reason for the blood request. |

### How to Add a Blood Request

1. Open the **Blood Request** module.
2. Click **Add Blood Request**.
3. Enter the patient name.
4. Enter the contact number.
5. Select the required blood group.
6. Select the component type.
7. Enter the number of units required.
8. Choose the required date and time.
9. Select the priority.
10. Enter the reason for the request.
11. Review the details carefully.
12. Click **Add** to save the request.

### Important Note

Make sure the request details are correct before saving because the record will be used for approval and allocation.

## Status Flow

Blood requests usually move through the following stages:

1. **Pending** - request is created and waiting for review
2. **Approved** - request is approved and can be allocated
3. **Partially Completed** - some units have been issued
4. **Completed** - full request has been fulfilled
5. **Declined** - request has been rejected
6. **Cancelled** - request or issue has been cancelled

![Blood Request status history](/screens/blood-request/Blood_Request_Sinlge_List3.png)

### Why This Status Flow Matters

The status flow helps users understand where each request is in the process and what action can be taken next.

## Important Notes

- Always verify the blood group, component type, and required units before approving.
- Enter a clear reason when rejecting or cancelling a request.
- Use the correct status tab to find requests faster.
- Review request details carefully before issuing blood.
- Make sure the allocation details are correct before confirming approval or issue.
- The Blood Request module is one of the core workflow modules in the system, so every action should be handled carefully.
