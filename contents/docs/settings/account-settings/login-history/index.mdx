The **Login History** section shows the user's login activity and access details.

## Overview

This page helps the user review the recent login records for their account.

![Login History](/screens/account/user-login-history/User_Login_History.png)

## Purpose

The purpose of this page is to help the user understand where and how the account was accessed.

## Page Layout

The page usually shows:

- login history list
- login date and time
- device or session details
- access-related information
- record view or detail actions

![Login Address Details](/screens/account/user-login-history/User_Login_Addressess.png)

## Detailed Login View

Some login records can be opened to view more detail.

![Login Detailed View](/screens/account/user-login-history/User_Login_Address_Details.png)

### What This Screen Shows

This screen shows:

- detailed login information
- session data
- selected record details
- additional access metadata

### How to Use This Screen

1. Open **Login History**.
2. Review the list of login records.
3. Check the login date, time, and session details.
4. Open a record if you want to see more information.
5. Review the detailed login view for security or access reference.

## Important Notes

- Use this page for account review and security checks.
- Review login details carefully if an access issue is suspected.
- The login history is read-only for end users.
