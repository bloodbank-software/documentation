The **Permission History** section shows a record of permission changes made for the user.

## Overview

This page helps the user review changes that were made to their permissions over time.

![Permission History List](/screens/account/user-permission/User_Permission_History_List.png)

## Purpose

The purpose of this page is to help the user understand when permission changes happened and who updated them.

## Page Layout

The page usually shows:

- permission history list
- changed-by information
- change date and time
- record controls and pagination
- filter area for narrowing the results

![Permission Filter](/screens/account/user-permission/User_Permission_Filter.png)

## How to Use This Screen

1. Open **Permission History**.
2. Review the list of permission changes.
3. Check who made the change and when it was applied.
4. Use the filter options if you need to narrow down the records.
5. Review the filtered result list.

## Important Notes

- This page is useful for security review and account monitoring.
- Use filters when the history list is long.
- Permission changes are shown as a record for reference.
