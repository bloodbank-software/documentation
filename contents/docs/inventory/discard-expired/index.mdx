The **Discard & Expired** workflow is used when a blood unit is not suitable for active use.

In the current inventory flow, discard is available only for units that fail quality checks.

## Overview

This section helps staff remove unsuitable units from active inventory in a controlled way.

![Inventory discard button for failed units](/screens/inventory/Inventory_Blood_DiscardButton_onlyfor_QualityCheckFailed.png)

## When Discard Is Available

The discard button appears only for blood units with a failed quality check status.

### What the User Sees

- the blood unit details page
- a Discard button
- the current failed status
- history and reason information

### How to Start a Discard

1. Open a quality check failed blood unit.
2. Click **Discard**.
3. Select the discard reason.
4. Enter remarks if needed.
5. Review the information carefully.
6. Confirm the discard action.

## How Expired Units Are Handled

Expired units are separated from active inventory and reviewed in the expired/discard workflow used by the system.

## Important Notes

- Discard should be used only when the unit is not suitable for future use.
- Always choose the correct discard reason.
- Review the unit status before confirming the action.
- Discarded units are kept for history and audit tracking.
