The **Inventory** module is the main area used to track blood units across the blood bank system.

It helps staff monitor stock, review unit status, add new units, open unit details, print barcodes, transfer safe units, and discard units that are no longer suitable for use.

## Overview

The Inventory module is used to manage blood units from the time they enter the system until their final workflow state.

From this module, users can:

- view current stock and summary counts
- search for a blood unit quickly
- review blood unit status and history
- add a new blood unit after collection or receipt
- print barcodes and use unit actions from the details page
- transfer safe stored units to another destination
- discard units that fail quality checks
- perform bulk transfer when multiple units move together

## Purpose

The main purpose of Inventory is to keep blood unit records organized and easy to follow.

Instead of checking different screens for stock, status, transfer, or discard actions, staff can use the Inventory module to manage the full unit lifecycle in one place.

## Module Structure

The Inventory section is organized into child pages so each screen is easy to use and understand.

### Available Pages

- Dashboard
- Blood Units List
- Add Blood Unit
- Blood Unit Details
- Print Barcode & Actions
- Transfer Blood Unit
- Discard & Expired
- Bulk Transfer
- Storage Units
- Other Bank
- Return

### How to Use This Section

1. Open the **Inventory** module.
2. Start with the dashboard or blood units list.
3. Open the required child page based on the task you want to complete.
4. Review the unit status before taking any action.

## Important Notes

- Always verify the blood unit status before transferring or discarding.
- Use the details page to review the full unit history before acting.
- Transfer is only allowed for eligible safe stored units.
- Discard is only allowed when the unit is not suitable for future use.
- Future workflow sections are listed here for the planned Inventory structure.
