The **Blood Unit Details** page shows the complete record for one blood unit.

This is the main page used to review status, check history, print barcode actions, and use status-based workflows.

## Overview

The details page helps staff understand the full lifecycle of a blood unit in one place.

From this page, users can:

- review unit identity and status
- see donor and screening information
- check audit trail and status history
- print barcodes when needed
- use transfer or discard actions when the unit status allows it

## Screening Not Done

This status means the unit has been collected, but screening tests have not started yet.

![Inventory blood unit details - screening not done](/screens/inventory/Inventory_Blood_DetailPage_ScreeningNotDoneStatus.png)

### What Users See

- unit summary
- current status
- status history
- screening not started state

### How to Use It

1. Open the blood unit from the list.
2. Review the status.
3. Confirm that screening has not started yet.
4. Use the next workflow step if screening needs to begin.

## Screening In Progress

This status means screening is being performed and some results may still be pending.

![Inventory blood unit details - screening in progress](/screens/inventory/Inventory_Blood_DetailPage_ScreeningInProgressStatus.png)

### What Users See

- test progress
- current screening state
- audit trail
- workflow history

### How to Use It

1. Open the blood unit details page.
2. Check the screening progress.
3. Review the available results.
4. Continue the screening workflow if required.

## Screening Safe

This status means the unit has passed the required screening checks and is safe for further inventory handling.

![Inventory blood unit details - screening safe](/screens/inventory/Inventory_Blood_DetailPage_ScreeningSafeStatus.png)

### What Users See

- safe status badge
- unit summary
- history and audit trail
- actions such as transfer or barcode options, if available

### How to Use It

1. Open the safe blood unit details page.
2. Review the screening summary.
3. Use the available actions if the unit needs to be transferred or printed.

## Quality Check Failed

This status means the unit failed quality verification and cannot continue in the normal active inventory flow.

![Inventory blood unit details - quality check failed](/screens/inventory/Inventory_Blood_DetailPage_QualityCheckFailedStatus.png)

### What Users See

- failed status badge
- reason or failure details
- audit trail
- discard-related action when available

### How to Use It

1. Open the failed blood unit details page.
2. Review the failure information.
3. Confirm that the unit should not remain in active use.
4. Use the discard workflow if required.

## What the Details Page Shows

- Unit ID
- Barcode
- Blood group
- Component type
- Collection location
- Storage information
- Current status
- Audit trail
- Status history
- Donor details
- Screening status summary

## Important Notes

- Review the status carefully before taking any action.
- Use the history section to understand how the unit moved through the workflow.
- Transfer and discard actions depend on the current unit state.
- The details page is the best place to verify the final unit status before acting.
