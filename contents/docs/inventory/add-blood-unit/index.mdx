title: Add Blood Unit
description: Register blood units collected from donors or received through other workflows.
---

The **Add Blood Unit** screen is used to register a new blood unit in inventory.

The form changes slightly depending on how the unit is added, such as a new collection, a return to stock, or receipt from another blood bank.

## Overview

This screen is used when a blood unit needs to enter the inventory for the first time or through another supported workflow.

The form keeps collection and source details in a structured way so the unit can be tracked correctly later.

### Common Fields

- collection or source type
- donor or source details
- collected by
- collecting location
- blood group
- component type
- volume
- collection date
- storage location
- QR or barcode details

## Collection Form

Use the collection form when a unit is being added after blood collection from a donor.

![Inventory add blood unit - collection form](/screens/inventory/Inventory_AddBloodUnit_CollectionForm.png)

### What Users Enter

- donor details
- collected by
- collecting location
- blood group
- component type
- volume
- collection date
- storage location

### Steps to Add a Collected Unit

1. Open **Add Blood Unit**.
2. Choose the collection type if shown.
3. Enter the donor and collection details.
4. Select the blood group and component type.
5. Enter the required volume and date.
6. Select the storage location.
7. Generate or scan the QR code if needed.
8. Review the details carefully.
9. Save the unit.

## Return Form

Use the return form when a unit is moving back into stock through the return workflow.

![Inventory add blood unit - return form](/screens/inventory/Inventory_AddBloodUnit_ReturnForm.png)

### What Users Enter

- returned unit information
- return source or reference
- blood group and component details
- reason for return
- storage location
- date and time of return

### Steps to Add a Returned Unit

1. Open **Add Blood Unit**.
2. Choose the return workflow if available.
3. Enter the unit or return reference details.
4. Select the blood group and component type.
5. Enter the return reason if required.
6. Choose the storage location.
7. Review the record.
8. Save the unit.

## Other Bank Form

Use the other bank form when the unit is received from another blood bank.

![Inventory add blood unit - other bank form](/screens/inventory/Inventory_AddBloodUnit_OtherBankForm.png)

### What Users Enter

- partner blood bank details
- received unit information
- blood group and component type
- quantity or volume
- receiving date
- storage location

### Steps to Add a Unit from Another Blood Bank

1. Open **Add Blood Unit**.
2. Choose the other bank workflow if available.
3. Select the sending blood bank.
4. Enter the unit details.
5. Select the blood group and component type.
6. Choose the storage location.
7. Review all details.
8. Save the unit.

## Important Notes

- Choose the correct source form before saving.
- Always verify the blood group, component type, and storage location.
- Use the QR code or barcode carefully so the unit can be tracked later.
- The data entered here becomes part of the blood unit record.
