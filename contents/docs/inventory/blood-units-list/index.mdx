The **Blood Units List** shows the full inventory table with unit-level records.

This is the main working list for reviewing blood units before opening details or taking an action.

## Overview

The blood units list helps staff review all stored or tracked blood units in one place.

From this screen, users can:

- search for a unit
- review unit status before acting
- open a blood unit details page
- use row actions when available

![Inventory blood list overview](/screens/inventory/Inventory_Blood_ListPage_Overview.png)

## What the List Shows

The table may include:

- Unit ID
- Blood group
- Component type
- Collected by
- Expiry date
- Source type
- Storage location
- Status
- Row actions

### Column Guide

| Column | Meaning |
|---|---|
| **Unit ID** | Unique reference for the blood unit. |
| **Blood Group** | The unit’s blood group. |
| **Component Type** | The blood component stored in the unit. |
| **Collected By** | The user or staff member who collected or entered the unit. |
| **Expiry Date** | The date on which the unit expires. |
| **Source Type** | How the unit entered inventory, such as collection or return. |
| **Storage Location** | Where the unit is currently stored. |
| **Status** | Current unit state in the workflow. |
| **Row Actions** | Quick actions for opening or managing the unit. |

## How to Use the List

1. Open the **Inventory** module.
2. Switch to the blood units list if needed.
3. Search for the required unit.
4. Review the status before taking any action.
5. Open the blood unit details page using the unit ID or action icon.

## Important Notes

- Always check the status before opening or changing a blood unit.
- Use the list for quick review and filtering.
- Open the details page when you need full history or status-based actions.
