The **Dashboard** is the first screen users usually open in the Inventory module.

It gives a quick summary of the current stock position and helps staff find blood units faster.

## Overview

The dashboard shows inventory health at a glance.

From this screen, users can:

- review stock totals
- check expiring and reserved counts
- search by unit ID or QR
- filter by blood group and status
- switch between blood unit view and storage view

![Inventory dashboard - blood units view](/screens/inventory/Inventory_Dashboard_by_BloodUnitsView.png)

## What the Dashboard Shows

The dashboard commonly displays:

- total available blood units
- expiring soon units
- screening units
- reserved units
- expired and discarded counts
- blood group wise stock cards

### Blood Units View

The blood units view gives a stock summary for the active blood unit list.

It helps staff understand how much usable stock is available and which groups need attention.

## Search and Filter

The dashboard includes quick search and filtering options.

Users can search by:

- unit ID
- QR code
- blood group

They can also filter by:

- blood group
- status

![Inventory dashboard - filter by and status](/screens/inventory/Inventory_Dashboard_FilterBy_And_Status.png)

### How to Use the Search and Filters

1. Open the **Inventory** dashboard.
2. Enter a unit ID or scan/search by QR if needed.
3. Select a blood group filter if you want to narrow the list.
4. Choose a status filter to review a specific stock state.
5. Review the updated results.

## Storage View

The dashboard can also show inventory from the storage point of view.

This view helps staff understand how units are arranged or counted in storage.

![Inventory dashboard - storage view](/screens/inventory/Inventory_Dashboard_by_StorageView.png)

## Important Notes

- Use the dashboard to get a quick stock summary before opening a specific unit.
- Search is the fastest way to find one unit when the list is large.
- Filters help users focus on a specific blood group or workflow state.
- The dashboard is a summary screen, so detailed actions are handled from the blood unit list or details page.
