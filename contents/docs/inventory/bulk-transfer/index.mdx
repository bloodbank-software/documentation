The **Bulk Transfer** option is used when multiple blood units need to be moved together to the same destination.

## Overview

Bulk transfer helps staff handle multiple stored units at once instead of transferring each unit separately.

![Inventory bulk transfer button usage](/screens/inventory/Inventory_Blood_ListPage_BulkTransferButtonUsage.png)

## How It Works

1. Open the blood units list.
2. Select the required units using the checkboxes.
3. Click **Bulk Transfer**.
4. Enter the transfer details for the selected units.
5. Review the selected records.
6. Confirm the transfer.

## What the User Should Know

- Bulk transfer is useful when multiple stored units go to the same destination.
- Only the selected units are included in the action.
- The user should review the records carefully before confirming.

## Important Notes

- Use bulk transfer only when the selected units share the same destination.
- Check the unit status before selecting records.
- Make sure the destination details are correct before confirming the transfer.
