The **Print Barcode & Actions** area is available from the blood unit details page.

It helps staff print the barcode label and open additional unit actions when needed.

## Overview

This section is used when the user needs barcode output or quick action access for a blood unit.

![Inventory blood unit details - print barcode options](/screens/inventory/Inventory_Blood_DetailPage_PrintBarcodeOptionsUsageandActions.png)

## What These Actions Do

- Print barcode for the unit
- Open additional unit options
- Support quick handling from the details page

## When the Action Is Visible

This action area appears from the blood unit details page.

It is used after opening a unit so the user can manage barcode output or other available unit actions.

## How to Use It

1. Open the blood unit details page.
2. Click the options or barcode action menu.
3. Choose the required action.
4. Print the barcode if the unit needs labeling or tracking output.

## Important Notes

- Barcode printing should be done from the correct unit record.
- Use the options menu carefully so the right action is selected.
- This area is for quick unit handling from the details page.
