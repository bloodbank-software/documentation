The Master Data section contains supporting reference pages used across the Blood Bank system.

Use these pages to manage standard values that appear in blood collection, inventory, screening, and related workflows.

## Available Pages

- Organization
- Roles Management
- Collecting Locations
- Partner Blood Banks
- Partner Hospitals
- Phlebotomist
- Lab Technicians
- Medical Officer
- Blood Groups
- Blood Component Types
- Rejection Reason
- Returns & Discards Reasons

## How to Use This Section

Open the required master page when you need to view or maintain a shared reference list.

Each page explains:

- what the record type means
- where it is used
- how to add or update records
- any status or usage rules that apply
