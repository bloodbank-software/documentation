## Lab Technicians

Lab Technicians are the staff members who perform laboratory screening and testing for blood units. This module helps the team maintain a structured list of lab technicians and use them consistently during the lab testing workflow.

![Lab Technicians listing page](/screens/master-data/labtechnician/LabTechnician_listing.png)

## Overview

The Lab Technicians module is used to manage all laboratory staff in one place.

From here, users can:

- view all lab technicians in a table
- add a new lab technician
- edit an existing lab technician
- mark a technician as active or inactive
- delete a technician when it is no longer needed

This module keeps laboratory staff information organized and makes it easier to use during blood testing workflows.

## Purpose

The main purpose of this module is to store and maintain lab technician details in a standard format.

Instead of entering staff details manually each time, users can select a saved technician from the list. This reduces mistakes and keeps the workflow consistent.

## Page Layout

The Lab Technicians page shows a table with the main details needed for daily work.

The page also includes an **Add Lab Technician** button for creating a new entry.

Each row contains action buttons that let users edit or delete the record as needed.

## Field Guide

| Field | Description |
|---|---|
| **Code** | Auto-generated code for the lab technician. |
| **Name** | Lab technician name. |
| **Employee ID** | Staff reference ID used to identify the person. |
| **Phone / Email** | Contact details for communication. |
| **Gender** | Optional personal detail if shown in the form. |
| **Status** | Shows whether the lab technician is **Active** or **Inactive**. |

![Lab Technicians actions](/screens/master-data/labtechnician/LabTechnician_actions.png)

## Actions Available

Each lab technician row supports the following actions:

- **Edit** - update lab technician details
- **Delete** - remove the technician if it is no longer required
- **Status** - review whether the technician is active or inactive

These actions help maintain the staff list without needing a separate screen.

## Add Lab Technician

Use this option when you want to create a new lab technician entry.

### Steps to Add Lab Technician

1. Open the **Lab Technicians** page.
2. Click **Add Lab Technician**.
3. Enter the technician name.
4. Enter the employee ID.
5. Enter the phone number or email address.
6. Select gender if it is available in the form.
7. Review the details carefully.
8. Save the record.

After saving, the new lab technician appears in the listing and becomes available for use where applicable.

![Add Lab Technician form](/screens/master-data/labtechnician/LabTechnician_add.png)

## Edit Lab Technician

Use the edit option when an existing lab technician needs to be corrected or updated.

### Steps to Edit Lab Technician

1. Find the required lab technician in the list.
2. Click the **Edit** button.
3. Update the required fields.
4. Review the changes.
5. Save the record.

Editing is useful when contact details change, the employee reference needs correction, or the status must be updated.

![Edit Lab Technician form](/screens/master-data/labtechnician/LabTechnician_edit.png)

## Status Handling

Lab Technicians can be maintained with two status values:

- **Active**
- **Inactive**

### Active

An active lab technician is available for selection during lab screening and testing workflows.

### Inactive

An inactive lab technician is kept in the system for reference, but it is not meant to be used for new operational entries.

This helps the team keep only valid and current staff records available for work.

![Lab Technician status handling](/screens/master-data/labtechnician/LabTechnician_status.png)

## Delete Behavior

If a lab technician is no longer needed, it can be deleted from the module.

### What happens when a technician is deleted

- a confirmation prompt appears first
- the user must confirm the action
- after confirmation, the technician is removed from the listing

This helps prevent accidental removal of staff records that may still be needed.

![Delete Lab Technician confirmation](/screens/master-data/labtechnician/LabTechnician_delete.png)

## Used In

Lab Technicians are used in the blood unit screening and testing flow.

When a user submits lab results for a blood unit, the system shows the available lab technicians in a dropdown. The user selects the person who performed the testing.

This keeps blood testing records consistent and helps the team identify who carried out the screening.

![Lab Technician usage in other workflows](/screens/master-data/labtechnician/LabTechnician_usage.png)

## Important Notes

- Keep lab technician names clear and easy to identify.
- Always maintain correct contact details for communication.
- Enter the employee ID carefully so each staff member can be identified correctly.
- Mark unused lab technicians as inactive instead of leaving them active.
- Delete a technician only when it is no longer needed.
- The technician selected during lab testing becomes part of the blood unit record.
