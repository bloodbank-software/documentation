Medical Officers are master data records used in donor-related workflows where medical assessment, approval, or donor questionnaire processing is required. This module helps the team maintain a structured list of medical officers that can be used across the system.

![Medical Officer listing page](/screens/master-data/medical-officer/MedicalOfficer_Listing.png)

## Overview

The Medical Officer module is used to manage all medical officer records in one place.

From this page, users can:

- view all medical officers in a table
- add a new medical officer
- edit an existing medical officer
- mark a medical officer as active or inactive
- delete a medical officer when it is no longer needed

This keeps medical officer information organized and makes it easier to use during donor workflows.

## Purpose

The main purpose of this module is to store and maintain medical officer details in a standard format.

Instead of entering medical officer details manually each time, staff can select a saved officer from the list. This reduces mistakes and keeps the workflow consistent.

## Page Layout

The Medical Officer page shows a simple listing view with the main details needed for daily work.

Typical columns include:

- Code
- Full Name
- Phone Number
- Email Address
- Registration Number
- Status
- Actions

### Field Guide

| Field | Description |
| --- | --- |
| **Code** | Auto-generated code for the medical officer. |
| **Full Name** | Medical officer name. |
| **Phone Number** | Contact number. |
| **Email Address** | Email address. |
| **Registration Number** | Medical council registration number. |
| **Status** | Shows whether the medical officer is active or inactive. |

The page also includes an **Add Officer** button for creating a new medical officer.

Each row contains action buttons that let users edit or delete the officer as needed.

![Medical Officer listing page](/screens/master-data/medical-officer/MedicalOfficer_Listing.png)

## Actions Available

Each medical officer row supports the following actions:

- **Edit** - update the officer details or status
- **Delete** - remove a medical officer when it is no longer needed
- **Status** - review whether the officer is active or inactive

These actions help users maintain the list without leaving the page.

## Add Medical Officer

Use this option when a new medical officer needs to be added to the system.

### Steps to Add Medical Officer

1. Open the **Medical Officers** page.
2. Click **Add Officer**.
3. Enter the full name.
4. Enter the phone number.
5. Enter the email address.
6. Enter the registration number.
7. Review the details carefully.
8. Save the record.

### What users should enter

- **Code** - this is auto-generated by the system
- **Full Name** - enter the medical officer name
- **Phone Number** - enter the contact number
- **Email Address** - enter a valid email address
- **Registration Number** - enter the official medical council registration number
- **Status** - set to active when the officer should be available for use

After saving, the new medical officer appears in the listing and becomes available wherever medical officers are used.

![Add Medical Officer form](/screens/master-data/medical-officer/MedicalOfficer_Add.png)

## Edit Medical Officer

Use the edit option when an existing medical officer needs to be corrected or updated.

### Steps to Edit Medical Officer

1. Find the required medical officer in the list.
2. Click the **Edit** button.
3. Update the required information.
4. Review the changes.
5. Save the record.

Editing is useful when contact details change, the registration number needs correction, or the status must be updated.

![Edit Medical Officer form](/screens/master-data/medical-officer/MedicalOfficer_Edit.png)

## Status Handling

Medical Officers can be in one of two states:

- **Active**
- **Inactive**

### Active

An active medical officer is available for selection during donor-related workflows where medical officer information is required.

### Inactive

An inactive medical officer is not shown in operational selection lists, so staff cannot choose it in daily workflows.

This helps the team keep only valid and usable medical officer records available.

## Delete Behavior

If a medical officer is no longer needed, it can be deleted from the module.

### What happens when a medical officer is deleted

- a confirmation popup appears first
- the user must confirm the action
- after confirmation, the officer is removed from the listing
- deleted medical officer records should no longer be used in future workflows

This prevents old or unused medical officer entries from being selected by mistake.

![Delete Medical Officer confirmation](/screens/master-data/medical-officer/MedicalOfficer_Delete.png)

## Used In

Medical Officers are used in donor workflows where medical assessment, approval, or questionnaire review is required.

This may include donor questionnaire processing, medical approval, and other medical-officer-related operations inside the blood bank system.

Using a saved medical officer list keeps officer information consistent and easy to reuse.

![Medical officer usage in donor workflow](/screens/master-data/medical-officer/MedicalOfficer_UsageinDonor.png)

## Important Notes

- Keep medical officer names clear and easy to identify.
- Always maintain correct contact details for communication.
- Mark unused medical officers as inactive instead of leaving them active.
- Delete a medical officer only when it is no longer needed.
- The medical officer selected in a workflow becomes part of the related donor record.
