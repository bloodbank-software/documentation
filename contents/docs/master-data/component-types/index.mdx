## Blood Component Types

Blood Component Types are predefined blood product categories used in the Blood Bank system. These values help the team store, manage, and identify blood products in a standard way.

![Blood Component Types listing page](/screens/master-data/component-types/ComponentTypes_listing.png)

## Overview

The Blood Component Types module is used to manage the standard blood component definitions available in the system.

From here, users can:

- view all blood component types in a table
- add a new component type
- edit an existing component type

This module keeps component information organized and ensures the same values are used consistently during blood unit creation and storage.

## Purpose

The main purpose of this module is to define the basic properties of each blood component in one place.

Using a fixed list of component types helps the system:

- keep component names consistent
- store correct shelf life and storage temperature values
- make blood unit handling easier
- standardize inventory and reporting data

## Page Layout

The Blood Component Types page displays a table with the main details needed for daily work.

The page also includes an **Add Component** button for creating a new component type.

Each row contains action buttons that let users edit the record as needed.

## Field Details

Each component type contains the following information:

| Field | Description |
|---|---|
| **Code** | Component code used to identify the blood component. |
| **Name** | Component name. |
| **Base Unit (mL)** | Standard volume for the component. |
| **Shelf Life (Days)** | How long the component remains valid. |
| **Storage Temperature** | Temperature range required for storage. |
| **Description** | Short description of the component. |

These details help the team understand how each component should be handled.

## Add Component Type

Use this option when you want to create a new blood component type.

### Steps

1. Open the **Blood Component Types** page.
2. Click **Add Component**.
3. Enter the component code.
4. Enter the component name.
5. Enter the base unit in milliliters.
6. Enter the shelf life in days.
7. Enter the storage temperature range.
8. Enter a short description.
9. Review the details carefully.
10. Save the record.

After saving, the new component type appears in the listing.

![Add Component Type form](/screens/master-data/component-types/ComponentTypes_add.png)

## Edit Component Type

Use the edit option when you need to update an existing component type.

### Steps

1. Find the required component type in the list.
2. Click the **Edit** button.
3. Update the required information.
4. Review the changes.
5. Save the record.

Editing is useful when the component information needs correction or adjustment.

![Blood Component Types edit page](/screens/master-data/component-types/ComponentTypes_edit.png)

## Used In

Blood Component Types are used in multiple parts of the Blood Bank workflow, including:

- blood unit creation
- inventory management
- storage handling
- lab testing and screening workflows
- reporting and dashboards

Because component types affect storage and shelf life, keeping this module accurate is important for day-to-day operations.

## Important Notes

- Keep component codes short and easy to identify.
- Make sure shelf life values are correct for each component.
- Store the correct temperature range for safe handling.
- Use clear descriptions so staff can quickly understand the component type.
- Update the master list carefully because it affects inventory and storage workflows.
