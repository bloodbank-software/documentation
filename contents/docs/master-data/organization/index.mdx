# Organization

The Organization module stores the main organization profile used throughout the application. It shows the organization identity, contact details, website, timezone, and address information in one place. Users can review the current profile and update it when needed.

![Organization overview page](/screens/master-data/organization/Organization_Overview.png)

## Overview

The Organization page is used to view and manage the main organization profile.

From this page, users can:

- view organization details
- check contact information
- review website and timezone data
- see address information
- update the organization profile when needed

This page acts as the central profile for the organization in the system.

## Purpose

The main purpose of this module is to maintain a single, official organization profile.

Instead of storing organization details in multiple places, the system keeps the core profile in one record so the information remains consistent across the application.

## Page Layout

The Organization page shows the profile in a simple read-only view with an edit option.

Typical items on the screen include:

- organization summary
- contact details
- website and timezone details
- created and updated timestamps
- address section
- edit action button

### Field Guide

| Field | Description |
|---|---|
| **Organization Name** | The official name of the organization. |
| **Organization Prefix** | Short code or prefix used for organization records. |
| **Registration Number** | Official registration reference number. |
| **Contact Email** | Email address used for communication. |
| **Website** | Official website link of the organization. |
| **Timezone** | System timezone used for date and time display. |
| **Phone Number** | Organization contact number. |
| **Address** | Registered organization address details. |
| **Primary** | Indicates the main or default address. |

## Edit Organization

Use the edit option when the profile details need to be corrected or refreshed.

![Edit Organization form](/screens/master-data/organization/Organization_Edit.png)

### Steps to Edit Organization

1. Open the **Organization** page.
2. Click **Edit**.
3. Update the required profile fields.
4. Review the contact and address information.
5. Save the changes.

### What users should update

- Organization name
- Organization prefix
- Registration number
- Contact email
- Phone number
- Website
- Timezone
- Address details

### Important Note

Make sure the updated details are accurate because the organization profile is used across the system.

## Address Information

The address section shows the official registered location for the organization.

### What This Section Shows

- address card or location card
- primary address marker
- street, city, state, postal code, and country details

### Why This Section Matters

The address section helps users confirm the official organization location and keeps profile data consistent for system-wide use.

## Important Notes

- Keep the organization profile accurate and up to date.
- Review the prefix and registration number carefully before saving changes.
- Update the email, phone, and website only when the official details change.
- Make sure the timezone is correct so date and time values display properly.
- The organization profile is a master record used by multiple areas of the system.
