## Partner Hospitals

Partner Hospitals are external hospitals that connect with the blood bank for requests, coordination, and related workflows. This module helps the team keep hospital details in one place and use them consistently in daily operations.

![Partner Hospitals listing page](/screens/master-data/partner-hospital/PartnerHospital_Listing.png)

## Overview

The Partner Hospitals module is used to manage all external hospital partners in one place.

From this page, users can:

- view all partner hospitals in a table
- add a new partner hospital
- edit an existing partner hospital
- mark a hospital as active or inactive
- delete a hospital when it is no longer needed

This module keeps hospital partner information organized and makes it easier to use during daily operations.

## Purpose

The main purpose of this module is to store and maintain partner hospital details in a standard format.

Instead of entering hospital details manually each time, staff can select a saved hospital from the list. This reduces mistakes and keeps the workflow consistent.

## Page Layout

The Partner Hospitals page shows a table with the main details needed for daily work.

The page also includes an **Add Partner Hospital** button for creating a new entry.

Each row contains action buttons that let users edit or delete the record as needed.

## Field Guide

| Field | Description |
|---|---|
| **Code** | Auto-generated code for the partner hospital. |
| **Name** | Partner hospital name. |
| **Contact Person** | The person to contact at the hospital. |
| **Phone / Email** | Contact details for communication. |
| **Address / City** | Hospital location details. |
| **Status** | Shows whether the hospital is **Active** or **Inactive**. |

![Partner Hospitals actions](/screens/master-data/partner-hospital/PartnerHospital_actions.png)

## Actions Available

Each partner hospital row supports the following actions:

- **Edit** - update hospital details
- **Delete** - remove the hospital if it is no longer required
- **Status** - review whether the hospital is active or inactive

These actions help maintain the partner list without needing a separate screen.

## Add Partner Hospital

Use this option when you want to create a new partner hospital entry.

### Steps to Add Partner Hospital

1. Open the **Partner Hospitals** page.
2. Click **Add Partner Hospital**.
3. Enter the hospital name.
4. Enter the contact person name.
5. Enter the phone number or email address.
6. Enter the address and city details.
7. Review the details carefully.
8. Save the record.

After saving, the new partner hospital appears in the listing.

![Add Partner Hospital form](/screens/master-data/partner-hospital/PartneHospital_add.png)

## Edit Partner Hospital

Use the edit option when an existing partner hospital needs to be corrected or updated.

### Steps to Edit Partner Hospital

1. Find the required partner hospital in the list.
2. Click the **Edit** button.
3. Update the required fields.
4. Review the changes.
5. Save the record.

Editing is useful when contact details change, the address needs correction, or the status must be updated.

![Edit Partner Hospital form](/screens/master-data/partner-hospital/PartnerHospital_Edit.png)

## Status Handling

Partner Hospitals can be maintained with two status values:

- **Active**
- **Inactive**

### Active

An active partner hospital is available for selection during workflows where hospital information is required.

### Inactive

An inactive partner hospital is kept in the system for reference, but it is not meant to be used for new operational entries.

This helps the team keep only valid and current partner records available for work.

![Partner Hospital status handling](/screens/master-data/partner-hospital/PartnerHospital_status.png)

## Delete Behavior

If a partner hospital is no longer needed, it can be deleted from the module.

### What happens when a hospital is deleted

- a confirmation prompt appears first
- the user must confirm the action
- after confirmation, the hospital is removed from the listing

This helps prevent accidental removal of hospital records that may still be needed.

![Delete Partner Hospital confirmation](/screens/master-data/partner-hospital/PartnerHospital_delete.png)

## Used In

Partner Hospitals are used in workflows where hospital details need to be selected or referenced.

This may include coordination, requests, and other hospital-related operations inside the blood bank system.

Using a saved partner hospital list keeps hospital information consistent and easy to reuse.

![Partner Hospital usage in other workflows](/screens/master-data/partner-hospital/PartnerHospital_usage.png)

## Important Notes

- Keep partner hospital names clear and easy to identify.
- Always maintain correct contact details for communication.
- Enter the address and city carefully so the hospital can be identified easily.
- Mark unused partner hospitals as inactive instead of leaving them active.
- Delete a partner hospital only when it is no longer needed.
- The partner hospital selected during a workflow becomes part of the related record.
