# Master Data

## Collecting Locations

Collecting Locations are the approved places where blood is collected from donors. These may include hospitals, camps, blood drives, or any other collection point approved by the organization.

This master module helps the team keep all collection points in one place and use them consistently while creating blood unit records.

![Collecting Locations listing page](/screens/master-data/collecting-location/Collecting_Location_Listing.png)

## Overview

The Collecting Locations module is used to maintain the list of places where blood collection takes place.

From this page, users can:

- view all collecting locations in a table
- add a new collecting location
- edit an existing collecting location
- mark a location as active or inactive
- delete a location when it is no longer required

This keeps collection records organized and helps staff select the correct location during blood unit entry.

## Purpose

The purpose of this module is to standardize collecting locations across the system.

Instead of typing the location name manually each time, staff can select from a saved list of approved locations. This helps reduce mistakes, improves consistency, and makes collection data easier to manage.

## Page Layout

The Collecting Locations page shows a simple listing view with the main details needed for daily work.

Typical columns include:

- Code
- Name
- City
- Address
- Status
- Actions

The page also includes an **Add Location** button for creating a new collecting location.

Each row contains action buttons that let users edit or delete the location as needed.

![Collecting Locations actions](/screens/master-data/collecting-location/Collecting_Location_Actions.png)

## Actions Available

Each collecting location row supports the following actions:

- **Edit** - update the name, city, address, or status
- **Delete** - remove a location when it is no longer needed
- **Status** - review whether the location is active or inactive

These actions help users maintain the list without leaving the page.

## Add Collecting Location

Use this option when a new collecting point needs to be added to the system.

### Steps

1. Open the **Collecting Locations** page.
2. Click **Add Location**.
3. Enter the collecting location name.
4. Enter the city and address.
5. Review the details carefully.
6. Save the record.

After saving, the new collecting location appears in the listing and becomes available for use where applicable.

![Add Collecting Location form](/screens/master-data/collecting-location/Collecting_Location_AddForm.png)

## Edit Collecting Location

Use the edit option when an existing collecting location needs to be corrected or updated.

### Steps

1. Find the required location in the list.
2. Click **Edit Icon**.
3. Update the required fields.
4. Review the changes.
5. Save the record.

Editing is useful when a location name changes, an address needs correction, or the status must be updated.

![Edit Collecting Location form](/screens/master-data/collecting-location/Collecting_Location_Edit.png)

## Status Handling

Collecting Locations can be maintained with two status values:

- **Active**
- **Inactive**

### Active

An active collecting location is available for use in daily workflows.

### Inactive

An inactive collecting location is kept in the system for reference, but it is not meant to be used for new operational entries.

This helps the team keep only valid and current collection points available for work.

![Collecting Location status handling](/screens/master-data/collecting-location/Collecting_Location_Status.png)

## Delete Behavior

If a collecting location is no longer needed, it can be deleted from the module.

### What happens when a location is deleted

- a confirmation prompt appears first
- the user must confirm the action
- after confirmation, the record is removed from the listing

This helps prevent accidental removal of locations that may still be needed.

![Delete Collecting Location confirmation](/screens/master-data/collecting-location/Collecting_Location_Delete.png)

## Used In

Collecting Locations are used in blood collection and inventory-related workflows.

When a blood unit is created, the staff member can choose the correct collecting location from the available list instead of typing it manually.

This makes the blood unit record more consistent and helps users identify where the collection took place.

![Collecting Location usage in other workflows](/screens/master-data/collecting-location/Collection_Location_Usage.png)

## Important Notes

- Keep collecting location names clear and easy to identify.
- Mark old or unused locations as inactive instead of deleting them unless they are no longer needed.
- Use the correct location during blood collection to keep records accurate.
- Deleting a location should be done carefully because it removes the record from the active listing.
- The collecting location selected during blood unit creation becomes part of the unit record.
