The **Logout** option lets the user safely end the current session and sign out of the system.

![Logout confirmation dialog](/screens/logout/Logout.png)

## Overview

The Logout option is available in the application sidebar at the bottom of the menu.

When the user clicks it, the system shows a confirmation dialog before ending the session. This prevents accidental logout and gives the user a chance to go back if needed.

## Purpose

The purpose of Logout is to securely sign out the current user from the system.

This helps protect the account, especially when:

- the user is sharing a device
- the user is finishing work for the day
- the user needs to switch to another account

## Page Layout

The logout screen includes:

- the Logout option in the sidebar
- a confirmation dialog
- a Go Back button
- a Log Out button
- a warning message explaining that the user will need to sign in again

## How to Log Out

1. Go to the sidebar.
2. Scroll to the bottom of the menu.
3. Click the **Logout** option.
4. Review the confirmation message.
5. Click **Log Out** to end the session.
6. Use **Go Back** if you do not want to leave the application.

## Logout Confirmation

After clicking the Logout option, the system opens a confirmation dialog.

The dialog asks the user to confirm whether they want to log out. This step is important because it prevents the user from leaving the session by mistake.

The dialog usually contains:

- a warning icon
- a logout message
- a **Go Back** button
- a **Log Out** button

## What Happens After Logout

When the user confirms logout:

- the current session is ended
- the user is signed out of the application
- the user must sign in again to access the system

This ensures the account remains secure after the session ends.

## Important Notes

- Always confirm before logging out if you are still working.
- If the application is being used on a shared system, always log out after use.
- Clicking **Go Back** cancels the logout action and keeps the session active.
- Clicking **Log Out** signs the user out immediately.
