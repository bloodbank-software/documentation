## Overview

The **Notes** tab is used to record internal or donor-related notes for future reference.

![Notes Tab - Listing](/screens/donor/DonorManagement_DonorDetails_NotesTab_Listing.png)

## What This Screen Shows

The notes section may include:

- existing notes list
- note type such as public or private
- note status
- edit and delete actions
- add note action

## How to Use This Screen

1. Open the donor profile
2. Click the **Notes** tab
3. Review existing notes
4. Click **Add Notes** to create a new note
5. Choose the note type if available
6. Save the note

## Add Notes

![Add Notes](/screens/donor/DonorManagement_DonorDetails_NotesTab_AddNotes.png)

## What This Screen Shows

The add notes form usually includes:

- note type selector
- note content area
- Add Notes button
- Cancel button
- optional note enhancement tools if available

## How to Add Notes

1. Open the donor profile
2. Go to the **Notes** tab
3. Click **Add Notes**
4. Choose the note type if needed
5. Enter the note content
6. Review the text carefully
7. Click **Add Notes**

## Important Note

Notes are useful for reminders, follow-up details, and internal donor observations.
