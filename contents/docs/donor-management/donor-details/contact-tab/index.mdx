## Overview

The **Contact** tab stores donor contact details such as phone numbers and email addresses.

![Contact Tab - Listing](/screens/donor/DonorManagement_DonorDetails_ContactTab_Listing.png)

## What This Screen Shows

The contact listing may include:

- system type such as phone or email
- contact type such as personal
- contact value
- active status
- edit action
- delete action
- add contact card

## How to Use This Screen

1. Open the donor profile
2. Click the **Contact** tab
3. Review the current contact records
4. Check whether the contact is active or inactive
5. Use edit or delete if changes are needed
6. Use **Add Contact** to add a new contact record

## Add Contact

![Add Contact](/screens/donor/DonorManagement_DonorDetails_ContactTab_AddContact.png)

## What This Screen Shows

The add contact form usually includes:

- system type selector
- contact type selector
- contact number or email value field
- Add Contact button
- Cancel option

## How to Add a Contact

1. Open the donor profile
2. Go to the **Contact** tab
3. Click **Add Contact**
4. Select the system type
5. Select the contact type
6. Enter the contact value
7. Review the details carefully
8. Click **Add Contact**

## Edit Contact

![Edit Contact](/screens/donor/DonorManagement_DonorDetails_ContactTab_EditContact.png)

## What This Screen Shows

The edit contact form usually includes:

- current contact details
- editable system type
- editable contact type
- editable contact value
- Update button
- Cancel button

## How to Edit a Contact

1. Open the donor profile
2. Go to the **Contact** tab
3. Click the edit icon on the required contact card
4. Update the necessary fields
5. Review the changes
6. Click **Update**

## Delete Contact

![Delete Contact](/screens/donor/DonorManagement_DonorDetails_ContactTab_DeleteContact.png)

## What This Screen Shows

The delete contact dialog usually includes:

- warning message
- Cancel button
- Yes, Delete button

## How to Delete a Contact

1. Open the donor profile
2. Go to the **Contact** tab
3. Click the delete icon on the contact card
4. Read the warning carefully
5. Click **Yes, Delete** only if needed
6. Use **Cancel** if you do not want to remove the contact

## Important Note

This tab keeps donor communication details organized and up to date.
