## Overview

The donor detail page shows the complete profile of one donor. This is the central page for reviewing and managing donor-related information.

![Donor Details Overview](/screens/donor/DonorManagement_DonorDetails_Overview.png)

## What This Screen Shows

The overview page usually contains:

- donor name
- DRN
- phone number
- gender
- blood group
- age or date of birth
- city
- email
- last donation date
- consent status
- notification preference
- action menu
- tab navigation

## How to Use This Screen

1. Open a donor from the listing
2. Review the summary header
3. Check the donor’s main profile details
4. Use the tabs to move to the required section
5. Use actions if editing or managing the donor is required

## Tabs Available

- Donation
- Communication
- Notes
- Contact
- Address

## Important Note

This page gives staff a full donor profile in one place and is used for detailed donor management.
