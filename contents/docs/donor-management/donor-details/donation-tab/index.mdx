## Overview

The **Donation** tab displays the donor’s donation history and related donation information.

![Donation Tab](/screens/donor/DonorManagement_DonorDetails_DonationTab.png)

## What This Screen Shows

The donation section typically includes:

- donation history
- unit ID
- donation date
- component type
- quantity or volume
- location
- blood bank name
- verified donation record if available

## How to Use This Screen

1. Open the donor profile
2. Click the **Donation** tab
3. Review the donation history
4. Check the verified donation record if shown
5. Use the information for donor follow-up or verification

## Important Note

It helps staff understand the donor’s previous donations and eligibility context.
