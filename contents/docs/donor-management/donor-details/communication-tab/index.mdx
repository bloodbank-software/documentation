## Overview

The **Communication** tab shows communication history and allows staff to add new communication records for the donor.

![Communication Tab - Listing](/screens/donor/DonorManagement_DonorDetails_CommunicationTab_Listing.png)

## What This Screen Shows

The communication listing may show:

- channel type
- date and time
- response status
- donor response text
- existing communication entries
- Add Communication card

## How to Use This Screen

1. Open the donor profile
2. Click the **Communication** tab
3. Review the existing communication history
4. Check the communication channel and response status
5. Click **Add Communication** if a new interaction must be recorded

## Add Communication

![Add Communication](/screens/donor/DonorManagement_DonorDetails_CommunicationTab_AddCommunication.png)

## What This Screen Shows

The add communication form usually includes:

- channel selector
- communication date and time
- response status
- donor response text
- Add button
- Cancel button

## How to Add Communication

1. Open the donor profile
2. Go to the **Communication** tab
3. Click **Add Communication**
4. Select the communication channel
5. Enter the date and time
6. Select the response status
7. Enter the donor’s response or follow-up text
8. Click **Add**

## Important Note

This tab is useful for tracking donor follow-up, reminders, and response history.
