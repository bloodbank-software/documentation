## Overview

The **Address** tab stores donor address records and location details.

![Address Tab - Listing](/screens/donor/DonorManagement_DonorDetails_AddressTab_Listing.png)

## What This Screen Shows

The address listing may include:

- address type
- street address
- country
- state
- city
- postal code
- map preview or location display
- add address card
- edit action
- delete action

## How to Use This Screen

1. Open the donor profile
2. Click the **Address** tab
3. Review the address entries
4. Check the location and postal details
5. Use edit or delete if needed
6. Click **Add Address** to add a new address record

## Add Address

![Add Address](/screens/donor/DonorManagement_DonorDetails_AddressTab_AddAddress.png)

## What This Screen Shows

The add address form usually includes:

- location search
- address type selector
- street address field
- country selector
- state selector
- city selector
- postal code field
- Add Address button
- Cancel button

## How to Add an Address

1. Open the donor profile
2. Go to the **Address** tab
3. Click **Add Address**
4. Search or enter the location
5. Select the address type
6. Fill in the street address
7. Select country, state, and city
8. Enter the postal code
9. Review the full address
10. Click **Add Address**

## Edit Address

![Edit Address](/screens/donor/DonorManagement_DonorDetails_AddressTab_EditAddress.png)

## What This Screen Shows

The edit address form usually includes:

- current address details
- editable address fields
- map or location input
- Update button
- Cancel button

## How to Edit an Address

1. Open the donor profile
2. Go to the **Address** tab
3. Click the edit icon on the address card
4. Update the required address details
5. Review the location carefully
6. Click **Update Address**

## Delete Address

![Delete Address](/screens/donor/DonorManagement_DonorDetails_AddressTab_DeleteAddress.png)

## What This Screen Shows

The delete address dialog usually includes:

- warning message
- Cancel button
- Yes, Delete button

## How to Delete an Address

1. Open the donor profile
2. Go to the **Address** tab
3. Click the delete icon on the address card
4. Read the warning message
5. Click **Yes, Delete** only if you are sure
6. Click **Cancel** if you do not want to delete the address

## Important Note

Address data is important for donor location tracking and operational use, so it should be maintained carefully.
