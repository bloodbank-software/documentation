title: Important Notes
description: Review the main rules and usage guidance for the Donor Management module.
---
## Access and Control

- Some actions may be restricted by role and permission
- Editing and deleting should only be done by authorized staff
- Support or impersonation actions should be used carefully

## Data Handling

- Donor data must be reviewed before saving
- Sensitive fields should be updated with care
- Contact and address changes may affect communication or operational workflows

## Operational Use

- Use search to find records quickly
- Use filters for better data control
- Use saved filters for recurring donor review tasks
- Use donor details tabs to keep profile data organized

## Safety

- Deletion actions require confirmation
- Updates should be verified before saving
- Messaging should be sent only to the correct donor group

## Module Importance

This module is one of the most important parts of the system because it drives donor operations, donor communication, and donor-related data management.
