## Overview

The **Donor Management** module is one of the main modules in the Blood Bank project.

It is used to manage donor records and all donor-related activities in one place. This module supports donor registration, internal donor handling, donor profile management, search, filtering, communication, notes, contacts, addresses, and donor-related actions used in other workflows.

![Donor Management Overview](/screens/donor/DonorManagement_Overview.png)

## What This Screen Shows

This screen is the main entry point for the donor module. It usually shows:

- module title
- total donor record count
- search area
- filter controls
- Add Donor action
- donor listing table
- row-level action icons

## How to Use This Screen

1. Open the Donor Management module from the sidebar
2. Review the total donor count
3. Use search if you need a specific donor
4. Apply filters if you want to narrow the list
5. Click **Add Donor** to create a new donor
6. Open a donor record from the listing to manage detailed donor information

## Important Note

This module is one of the most important parts of the system because it is the central place where staff manage donor data, donor operations, and donor profile details used across the application.
