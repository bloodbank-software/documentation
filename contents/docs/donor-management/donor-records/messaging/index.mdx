## Overview

The **Messaging** feature is used to send notifications or follow-up messages to selected donors. It helps staff communicate with donors for reminders, follow-ups, campaigns, or other donor-related communication needs.

![Messaging](/screens/donor/DonorManagement_Messaging.png)

## What This Screen Shows

The messaging screen usually shows:

- selected donors list
- send notification panel
- communication channel tabs such as WhatsApp, SMS, or Email
- message text area
- schedule date and time field
- attachment option
- send button
- cancel button

## How to Use This Screen

1. Select one or more donors from the donor listing
2. Open the messaging action
3. Review the selected donors
4. Choose the communication channel
5. Enter the message content
6. Set a schedule if required
7. Attach a file if needed
8. Click the send action to deliver the message

## What the User Can Do Here

- send a message to one donor or multiple donors
- choose the communication channel
- schedule the message for later
- add attachments if required
- review the selected recipients before sending

## Important Note

This feature should be used carefully because the message will be sent to the selected donor set.
