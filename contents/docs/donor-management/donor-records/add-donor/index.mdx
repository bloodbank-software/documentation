## Overview

The **Add Donor** screen is used to create a new donor record in the system.

![Add Donor](/screens/donor/DonorManagement_AddDonor.png)

## Steps to Add a Donor

1. Click **Add Donor** from the donor listing page
2. Enter the donor’s name
3. Select the birth date
4. Choose gender
5. Select blood group
6. Enter last donation details if available
7. Enter identifier details if required
8. Fill contact and address information
9. Review camp and consent options
10. Click **Add Donor** to save the record

## What You Need to Enter

This page is used to create a complete donor record.

When adding a donor, staff should provide the basic identity details first, then add contact and address information so the donor can be reached later if needed. If the donor has donated before, the last donation details can also be added.

The form may also include consent and camp-related options. These should be checked carefully before saving because they affect how the donor record is used later in the system.

## What to Check Before Saving

- required fields are filled correctly
- blood group is selected correctly
- contact number is valid
- address is correct
- consent details are reviewed
- location search result is accurate

## Important Note

This is the first step in creating a donor record, so all details should be entered carefully.
