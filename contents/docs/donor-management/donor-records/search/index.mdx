## Overview

The search controls help staff quickly locate donor records without browsing through the full table.

![Search](/screens/donor/DonorManagement_Search.png)

## What This Screen Shows

This screen demonstrates the two main search methods:

- **Global Search**
- **DRN Search**

## Global Search

Use global search to find donors by general information such as:

- donor name
- mobile number
- other donor record details

## DRN Search

Use DRN search when you already know the donor’s DRN and want to open that exact donor record directly.

## How to Use Search

### Global Search

1. Click the global search box
2. Enter the search text
3. Wait for the list to update
4. Review the matching donors
5. Open the correct record

### DRN Search

1. Switch to DRN search if available
2. Enter the DRN
3. Review the result
4. Open the exact donor record

## Important Note

Search is one of the fastest ways to find a donor when the list contains many records.
