# Filters and Saved Filters

## Overview

The filter system helps staff narrow donor records using donor attributes, status, location, date range, and other criteria. Saved filters let staff store a useful filter setup and reuse it later.

![Filters and Saved Filters](/screens/donor/DonorManagement_Filters_And_SavedFilters.png)

## What This Screen Shows

This screen may include:

- blood group filters
- status filters
- gender filters
- age filters
- date range filters
- country, state, and city filters
- camp name filters
- filter name input
- save button
- saved filter list
- load and delete saved filter actions

## How to Use Filters

1. Open the filters panel
2. Select the required filter values
3. Review the filtered donor list
4. Save the filter if you need to reuse it later
5. Load the saved filter when needed
6. Remove a saved filter if it is no longer useful

## How Saved Filters Work

Saved filters help staff avoid repeating the same setup every time. This is useful for:

- regular donor review
- location-based follow-up
- blood group-based donor search
- age or status-based filtering

## Important Note

Saved filters are especially helpful when the same donor grouping is used again and again.
