## Overview

The **Donor Listing** page shows all donor records in a table format. This is the main screen used by staff to review donor data and perform actions on individual donor records.

![Donor Listing](/screens/donor/DonorManagement_Listing.png)

## What This Screen Shows

The listing usually includes:

- created date
- donor profile
- DRN or camp name
- mobile number
- donation summary
- location
- status
- action column
- pagination
- rows per page selection

## What the Columns Mean

- **Created At**: When the donor record was created
- **Profile**: Donor name, blood group badge, age, and gender
- **DRN / Camp Name**: Donor registration number or camp reference
- **Mobile Number**: Primary contact number
- **Donation Summary**: Summary of donation-related data
- **Location**: Donor location and city/state details
- **Status**: Current donor status
- **Action**: Quick actions such as edit or delete

## How to Use This Screen

1. Open Donor Management
2. Review the donor rows shown in the table
3. Use pagination to navigate through pages
4. Change rows per page if needed
5. Use the action icons to edit, view, or delete the donor
6. Open a donor profile to manage detailed information

## Important Note

The donor listing is the main working area for most donor operations.
