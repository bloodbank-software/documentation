## Overview

The **Delete Donor** action removes a donor record after confirmation.

![Delete Donor](/screens/donor/DonorManagement_DeleteDonor.png)

## What This Screen Shows

This screen shows:

- the donor row being deleted
- the delete action
- a confirmation dialog
- a warning message
- Cancel button
- Yes, Delete button

## Steps to Delete a Donor

1. Locate the donor in the listing
2. Click the delete icon in the action column
3. Read the confirmation message carefully
4. Confirm only if the donor record should be removed
5. Click **Yes, Delete**
6. Click **Cancel** if you do not want to proceed

## Important Behavior

- Delete is a sensitive action
- The system asks for confirmation before removing the record
- Staff should verify the donor carefully before confirming

## Important Note

Deletion should be used only by authorized users and only when the record really needs to be removed.
