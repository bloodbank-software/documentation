## Overview

The **Edit Donor** screen is used to update an existing donor record.

![Edit Donor](/screens/donor/DonorManagement_EditDonor.png)

## What This Screen Shows

The edit donor form usually includes:

- donor name
- birth date
- gender
- blood group
- last donation date
- identifier details
- consent information
- blood camp setting
- contact details
- address details
- Update button
- Cancel button

## How to Edit a Donor

1. Open the donor record
2. Click the **Edit** action
3. Modify the required details
4. Check the updated fields carefully
5. Click **Update Donor**

## What to Check Before Updating

- make sure the changes are correct
- review sensitive values carefully
- confirm contact and address fields
- check blood group and date details
- verify consent options if changed

## Important Note

Editing changes the official donor record, so the user should review all data before saving.
